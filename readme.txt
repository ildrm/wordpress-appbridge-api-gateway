Secure, extensible WordPress application API gateway for mobile, web, headless and integration clients.

== Description ==

AppBridge API Gateway provides a hardened, versioned facade for WordPress application clients with bearer sessions, refresh-token rotation, rate limiting, CORS controls, audit logs, webhooks, device registration, notifications, WordPress Abilities, WooCommerce, ACF and Gravity Forms integration surfaces.

== Installation ==

1. Upload and activate the plugin.
2. Open AppBridge in WordPress admin.
3. Configure CORS origins and security settings.
4. Use HTTPS in production.
